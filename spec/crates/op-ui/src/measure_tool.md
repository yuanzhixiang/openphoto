
# measure_tool.rs
The Ruler draws a line, moves endpoints or the whole line, and uses Alt from an endpoint to add a protractor leg. Shift constrains endpoint drags to axes/45-degree directions. Escape/tool switch restores the starting measurement; double-click clears it. Measurements are session metadata and do not affect document/history. The options bar shows pixel X/Y, signed W/H, clockwise line angle or unsigned angle between legs, L1 and optional L2. Clear removes measurement. Straighten Layer rotates transformable selected/linked pixels around their bounds to the nearest horizontal/vertical axis using existing bicubic transform, records one state and clears the ruler. Locked backgrounds do not straighten. Physical/custom measurement scales and exact native styling are unimplemented.
