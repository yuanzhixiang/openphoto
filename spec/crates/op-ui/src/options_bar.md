# options_bar.rs: Top options bar

## Component responsibility

The tool options bar at the top of the window; its content changes with the current tool. Corresponds to Photoshop's Options Bar.

## Layout

33 pt high, background `#535353`, vertical center 17 pt below the top of the options bar. The frame is drawn at absolute positions measured from Photoshop 2026 (measured pixel by pixel from 2x screenshots); all x coordinates below use the left end of the options bar as the origin, in pt:

1. Grip: a column of 10 small 2 × 1 pt `#454545` dots at x 5.5, starting 8 pt below the top, spaced 2 pt apart.
2. Home button: icon center x 28, solid house icon.
3. Separator: x 53.
4. Tool preset: icon center x 68.5; the Move tool draws Photoshop's four-way arrow, other tools use Phosphor Bold icons for now. Dropdown arrow center x 90.25.
5. Separator: x 102.
6. Options for the current tool, starting at x 110 (see below).
7. Right-aligned, distance from center to the window's right edge: Share 200, Notifications 163.5 (the bell is a darker `#b9b9b9`), Search 131, Discover 98.5, Workspace 69.5, dropdown arrow 48, avatar placeholder circle 21.5 (diameter 24). While text is being entered, this group is replaced by Cancel (⦸) and Commit (✓) buttons.

Separators are all 1 pt wide, 22.5 pt high `#3e3e3e` vertical lines (starting 6 pt below the top). Icon color `#dddddd`; button hit areas are 24 pt square with a rounded background on hover. All icons are vector shapes traced from Photoshop (see `ps_icons.md`), not an icon font.

Home, Tool preset, and the right-side icons only have appearance and hover tooltips; clicking them does nothing.

The fields are disabled when there are free corners (after distorting).

## Known limitations

The options bar frame, the options for all tools, and the Crop, Free Transform, and Warp bars are all positioned according to Photoshop 2026 measurements. Which settings actually take effect and which are only stored in `tool_settings` is described in `options_tools.md` and in the per-tool notes above.
