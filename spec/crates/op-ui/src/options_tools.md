# options_tools.rs: Tool options bars laid out from control tables

## Component responsibilities

Writes the tools' options bars as control tables (`Item`): separators, labels, brush pickers, icon buttons, toggle icons, dropdowns, input fields, percentages (input field plus slider arrow box), checkboxes, disabled checkboxes and swatches. Coordinates are "bar coordinates" measured on Photoshop 2026 options bar screenshots (see `options_kit.md`). `layout(tool)` returns a tool's control table, and `show` draws it item by item and handles interaction. Currently covered: Brush, Pencil, Color Replacement, Mixer Brush, Eraser, Background Eraser, Magic Eraser, Clone Stamp, Pattern Stamp, History Brush, Art History Brush, Blur, Sharpen, Smudge, Dodge, Burn, Sponge; Spot Healing Brush, Healing Brush, Patch, Content-Aware Move, Red Eye; Gradient, Paint Bucket; Eyedropper, Color Sampler, Ruler, Note, Count; Pen, Freeform Pen, Curvature Pen, Add/Delete Anchor Point, Convert Point; Horizontal/Vertical Type and the two type masks; Path Selection, Direct Selection; Rectangle, Ellipse, Triangle, Polygon, Line, Custom Shape; Hand, Rotate View, Zoom; Artboard, Perspective Crop, Slice, Slice Select, Frame; Selection Brush, Remove Tool, Adjustment Brush. There are also selection boxes with text (`LabeledRadio`), menu buttons (`MenuButton`), segmented buttons (`Segments`), radio icons (`Radio`, e.g. the five gradient types), buttons, disabled dropdowns, an empty pattern box, color blocks, a gradient swatch (the tool's gradient, `AppState::tool_gradient`, reversed when Reverse is checked; clicking it opens the Gradient Editor for the tool, and its chevron opens the presets, `AppState::gradient_presets`, as a native pop-up menu whose pick becomes the tool's gradient) and the four selection-operation buttons (`Modes`).

Controls added later: disabled icons (`IconOff`), marker-only icons (`Glyph`, e.g. the font size, corner radius and polygon sides icons, not clickable), dimmed labels (`LabelOff`), disabled empty input fields (`FieldOff`) and combo boxes (`ComboOff`), combo boxes (`Combo`: input field plus arrow menu), centered notices (`Notice`), the foreground fill swatch (`FillSwatch`), the no-stroke swatch (`NoStroke`), the line style dropdown (`LineStyle`), color blocks with a dark border (`ColorFrame`; `fg` is the foreground color, `artboard.bg` follows the artboard background dropdown as white, black, or the gray of transparency), buttons that perform actions (`Action`), the view rotation dial (`Dial`), the custom shape picker (`ShapePicker`), dropdowns with icons (`IconPopup`, the Frame tool's stroke position) and the slice width/height (`SliceSize`, disabled when Style is Normal, editable after choosing a fixed aspect ratio or fixed size).

## Reading and writing settings

Each control carries a key:

- Keys bound to real state: `paint.opacity`, `paint.flow` (the opacity and flow of the current tool's `PaintOptions`; the Strength of Blur and Sharpen and the Exposure of Dodge and Burn are also the opacity), the brush picker (size and hardness of `PaintOptions`), `dodge.range` / `burn.range` (the tonal range of `RetouchOptions`), `sponge.mode` (Desaturate / Saturate), `clone.aligned`, `gradient.kind` and `gradient.reverse` (`AppState::gradient`), `bucket.mode`, `bucket.opacity`, `bucket.tolerance`, `bucket.anti_alias`, `bucket.contiguous`, `bucket.all_layers` (`AppState::bucket`), `eyedropper.size` and `eyedropper.sample` (`AppState::eyedropper.sample`: Current Layer, Current & Below, All Layers; the two No Adjustments options behave like All Layers and Current & Below respectively, and the chosen item is also stored in the settings for display), and the Clone Stamp's `clone.sample` (`clone_scope`). These all take effect as before. The Color Sampler's `sampler.size` is the Sample Size its readouts in the Info panel average over, and its Clear All (`Action`, 310–371.5) removes the active document's samplers.
- Keys of the type, shape and view tools bound to real state: `type.style` (`TypeOptions::semibold`), `type.size` (`TypeOptions::size_pt`, 0.5–1296), `shape.sides` (`ShapeOptions::sides`, 3–100), `shape.weight` (`ShapeOptions::weight`, 1–1000 px); `zoom.out` (the Zoom tool zooms out on click, see `document_view.md`); among the `Action` buttons, 100%, Fit Screen and Fill Screen act on the current document, Front Image / Clear write the Perspective Crop input fields, and Reset View turns the document's view back to 0°; `rotate.angle` is the document's `View::rotation`. The text color and the shape Fill show the current foreground color (both type and shapes use the foreground color); shapes draw no stroke, so Stroke shows as no color. The font can only be the built-in Source Sans 3; typing another font name has no effect.
- The Mixer Brush's swatch shows its load color (`AppState::mixer_load`, else the foreground color). Its combination pop-up (`mixer.combo`) lists Custom and Photoshop's twelve combinations (Dry, Moist, Wet and Very Wet, each also Light Load and Heavy Load). Picking one sets Wet, Load and Mix (`MIXER_SETTINGS`: Dry 0%, Moist 10%, Wet 50%, Very Wet 100% wet; Load 50%, Light 1%, Heavy 100%, with Moist's plain load 5%; Mix 50%), and typing Wet, Load or Mix makes it Custom. These values are provisional (not measured).
- The Pattern Stamp's swatch shows the chosen pattern tiled a pixel a point (`options_kit::pattern_swatch`); its chevron box opens the patterns as a native pop-up menu (the current one checked), whose pick becomes `AppState::pattern`.
- The Smudge tool's `smudge.strength` and the Pattern Stamp's `pattern.opacity` / `pattern.flow` are bound to the opacity and flow of their own `PaintOptions`; sampling for the Background Eraser and Color Replacement is a three-way choice `bgeraser.sampling` / `colorreplace.sampling` (Continuous, Once, Background Swatch, default Continuous), read and applied by `color_match` / `replace_mode` together with Limits, Tolerance, Protect Foreground Color and Color Replacement's Mode.
- The Brush's `brush.mode`, the Pencil's `pencil.mode` (`paint_mode`: converted to `PaintMode`) and the Eraser's `eraser.mode` (`eraser_mode`: Brush / Pencil / Block) are stored in `tool_settings` and read and applied by `document_view.rs` when a stroke starts.
- All other keys are stored in `AppState::tool_settings` (as text; checkboxes and toggles as `1` / `0`; dropdowns as the index): they can be changed and are kept for the current run, but have no effect yet. Brush sizes for tools without `PaintOptions` (Pattern Stamp, Art History Brush, Color Replacement, Mixer, Background Eraser, Smudge) are also stored here.
- Defaults follow Photoshop: the Mixer Brush's "Load / Clean after each stroke" and the Background Eraser's and Color Replacement's "Continuous sampling" are pressed by default; Color Replacement's Mode defaults to Color and Limits to Contiguous; Protect Tones, Protect Detail, Vibrance, Aligned, Anti-alias, Dither, Show Sampling Ring, Use Measurement Scale and Transform On Drop are checked by default; the Gradient's Method defaults to Smooth; Diffusion for Healing and Patch defaults to 5.
- Percentage input is limited to 0–100% (1–100% for the Brush's opacity and flow). Input fields write back only when editing ends; slider boxes write back immediately while dragging.

## Brush picker

Clicking it pops up the brush picker popup (`brush_presets.md`): Size, Hardness (not on the Pencil), the tip's angle and roundness, and the General Brushes presets. The options bar's "Always use pressure for opacity / size" toggles and Smoothing take effect (`document_view.md`).

## Known differences

- Initial values of brush size, opacity, etc. are this program's defaults; the Photoshop screenshots show the state at the time (e.g. a 13 px brush).
- The Mixer's smoothing icon, symmetry (butterfly), airbrush, angle gradient and similar icons are approximate redrawings from the screenshots; the Ruler's readout is currently fixed at 0.
- The various panel toggles (Brush Settings, Clone Source) and buttons such as symmetry, smoothing options (the gear) and ignore adjustment layers have no effect yet.
- The Pen, Path Selection, Artboard, Perspective Crop, Slice, Slice Select and Frame tools themselves are not implemented yet; their options are only stored in `tool_settings`. Icons such as path operations/alignment/arrangement, gear, Warp Text and panel toggles are appearance only.
- The Remove Tool and Adjustment Brush themselves are not implemented yet; their options are only stored in `tool_settings`. The Remove Tool's feedback icon and the Adjustment Brush's Select Subject icon are approximate drawings. The Move tool's bar is laid out separately by `options_bar.rs` (its separators and edges also match Photoshop).

- `brush_options_bars_edit_their_settings`: after entering 50 for the Brush's Opacity, the opacity is 0.5; the airbrush toggle writes the setting; after unchecking the Clone Stamp's Aligned, `RetouchOptions::clone_aligned` is false.

## Healing tools

`heal_options` reads the Healing Brush's Aligned (default off) and Sample (Current Layer, Current & Below, All Layers), the Spot Healing Brush's Sample All Layers, the Patch tool's Source / Destination segment and Content-Aware Move's Move / Extend, which `document_view.rs` uses when a stroke or patch starts.

## Magnetic Lasso

`magnetic_options` reads the Magnetic Lasso's Width (pixels, 1–256, default 10), Contrast (1–100%, default 10%) and Frequency (0–100, default 57) for `document_view.rs`.

## Quick Selection and Object Selection

`quick_options` reads the Quick Selection tool's mode (0 New, 1 Add, 2 Subtract), brush diameter (`quick.size`, default 30), Sample All Layers and Enhance Edge; `object_options` reads the Object Selection tool's Sample All Layers and Hard Edge (default on).
