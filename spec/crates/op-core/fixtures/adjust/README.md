# fixtures/adjust: Photoshop 2026 Adjustment Results

The `photoshop` tests in `adjust.rs` use these files to compare against Photoshop's output:

- `probe.rgb`: a 64 × 72 RGB probe image (the first 64 rows are a 16-level RGB cube, then 4 rows of 0–255 gray ramps, and finally 4 rows of random colors).
- `hs_*.rgb`, `hr_*.rgb`: the results of Photoshop running Hue/Saturation (Master, Colorize, color ranges) on the probe image; the settings are written in the tests.
- `cm*.rgb`, `sc_*.rgb`, `bw_*.rgb`, `pf_*.rgb`, `ex_*.rgb`, `vib_*.rgb`, `gm_*.rgb`: Photoshop's results for Channel Mixer, Selective Color, Black & White, Photo Filter, Exposure, Vibrance and Gradient Map.
- `levels.bin`, `brightness_contrast.bin`: one row per 256 bytes, Photoshop's output after running each setting on a 0–255 gray ramp (the settings are in the tests' `LEVELS_ROWS` and `BRIGHTNESS_CONTRAST_ROWS`).
- `color_balance.rgb`: 256 RGB pixels per row, the results of 80 random Color Balance settings (`COLOR_BALANCE_ROWS`) applied to a gray ramp.

All are generated by scripts driving Photoshop (each row applies one set of parameters through a selection, saved as PNG and read back); do not edit them by hand.
