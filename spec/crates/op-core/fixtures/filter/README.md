# fixtures/filter: Photoshop 2026 filter results

`filter.rs`'s `photoshop::filters_match_photoshop` uses these files to compare against Photoshop:

- `probe.rgb`: a 64 × 64 RGB probe image (red-green gradient background, a white square, a black line, scattered colored dots).
- `f_*.rgb`: the results of Photoshop 2026 running each filter on the probe image (Gaussian Blur 0.3/1/2.5/10, Box Blur, Unsharp Mask, Median, Minimum/Maximum, High Pass, Mosaic, Solarize, Blur, Blur More, Sharpen, Sharpen More, Find Edges, Motion Blur, Emboss, Fragment, Custom (`f_cust` is a 3 × 3 sharpen kernel with scale 4 and offset 10, `f_cust2` is a 5 × 5 kernel of all 1s with scale 25), Surface Blur (`f_surf` radius 5 threshold 15, `f_surf2` radius 2 threshold 40), Dust & Scratches (`f_dust` radius 2 threshold 0, `f_dust2` radius 3 threshold 20), Despeckle (`f_desp`), Sharpen Edges (`f_shrpe`), Trace Contour (`f_trace` Level 128 Upper, `f_tracel` Level 100 Lower), etc.); the parameters are written in the tests.

They are generated by a script driving Photoshop; do not edit them by hand. There are also measurements not checked in: the Gaussian Blur kernel was measured from a one-dimensional impulse (a vertical line) in 16-bit grayscale, and the Motion Blur, Emboss and Minimum kernels were measured from single-pixel impulses.
