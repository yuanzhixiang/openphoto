# data/brightness_contrast.bin: Photoshop's Brightness/Contrast Curves

452 × 256 bytes: the first 301 rows are Photoshop 2026's output for each level 0–255 at brightness −150…150 (contrast 0), and the last 151 rows are the output at contrast −50…100 (brightness 0). Brightness/Contrast (non-Legacy) in `adjust.rs` looks up the brightness row first, then the contrast row.

The data was generated by a script in Photoshop 2026: a 256 × 470 image with one gray ramp per row, each row running Brightness/Contrast once through a selection, saved as PNG and read back (the combination and Legacy rows captured along with it are in `fixtures/adjust/brightness_contrast.bin`, used for tests). To update it, recapture it the same way; do not edit it by hand.
