# Git 忽略规则（.gitignore）

## 职责

列出源码仓库不跟踪的文件：构建产物和编辑器、操作系统产生的本地文件。

## 行为规则

- `/target`：只忽略仓库根目录下的 Cargo 构建输出目录（工作区共用一个 target）。
- `.DS_Store`：任意层级的 macOS Finder 元数据文件。
- `.idea/`：JetBrains IDE 配置目录（任意层级）。
- `.vscode/`：VS Code 配置目录（任意层级）。

## 边界情况

- `Cargo.lock` 不在忽略列表中，会被提交：本仓库包含可执行程序，锁定依赖版本以保证可复现构建。
- spec 目录 `spec/` 和根目录的 `CLAUDE.local.md` 不写在 `.gitignore` 中，而是通过本地的 `.git/info/exclude` 忽略（见 `spec/CLAUDE.md`）；新克隆的仓库需要手动添加这两条，否则 `spec/` 会显示为未跟踪内容。

## 与其它模块的关系

- 与 `.git/info/exclude` 配合：前者是所有人共享的规则，后者是每台机器本地的规则。

## 已知限制

- 只覆盖 JetBrains 和 VS Code 两种编辑器的配置目录，其它编辑器或工具产生的本地文件不在忽略范围内。
