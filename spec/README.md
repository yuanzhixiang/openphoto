# OpenPhoto Product Specification Overview

## Product Positioning

OpenPhoto is a Photoshop clone written in Rust. Its goal is to match Photoshop 2026 in features, interaction, and keyboard shortcuts, and to match the original Photoshop interface pixel for pixel (compared pixel by pixel at the same window size). The reference is a running Photoshop 2026 (macOS, default "Medium Gray" theme, Essentials workspace). The specific behavior of each module is in the spec at the corresponding source path; the overall UI-layer specification is in `crates/op-ui/src/README.md`.

Besides the graphical interface, `op-mcp` is an MCP server: AI agents use it to invoke the same editing operations as the interface (adjustments, filters, layers, selections, canvas, fill, history); see `crates/op-mcp/src/main.md`.

## Feature Gaps Relative to Photoshop

This section lists features that Photoshop 2026 has and OpenPhoto currently lacks (or has only in part), ordered by priority. The data comes from Photoshop 2026's menus, toolbar, and panels. Each item is deleted or rewritten here as soon as it is filled in, so this section always describes the current gaps.

Priorities:

- **P0**: An existing interface differs from Photoshop, or a feature required by the most basic editing flow (open → select → paint/modify → undo → export) is missing.
- **P1**: Commonly used editing features.
- **P2**: Fairly commonly used features that take substantial implementation work.
- **P3**: Professional, rarely used, or Adobe cloud-dependent features.

### P0

1. **Pixel-level calibration of existing interfaces**: Image Size (Photoshop also has a preview image on the left), Fill, Trim, and the adjustment and filter dialogs are aligned pixel by pixel; the Layers panel's rename field and drag indicator line are measured against Photoshop 2026; the window frame (the outer dimensions of the title bar, options bar, toolbar, icon column, and panel column; the document tab bar, scroll bars, status bar), the History panel, and the Color Picker are measured 1:1 against Photoshop (the Color Picker's hex field receives focus on open, and the marker in the color field is clipped to the field). The options bars of all tools are positioned one by one against Photoshop 2026 screenshots (separators and the edges of the various boxes differ by no more than 1 pt). What has not yet been compared pixel by pixel: the details of the toolbar icons (each has been redrawn in Photoshop's style and aligned in position, but the shapes of the line-style icons are still approximate; see `crates/op-ui/src/tool_icons.md`). The panel column's collapse bar, group heights, tab bar, Color, Properties (including the Rulers & Grids, Guides, and Quick Actions sections after Canvas), the Layers panel, the icon column, and the bottom of the toolbar are aligned pixel by pixel; the Canvas Size, Fill, Trim, New Guide, and Select › Modify dialogs and the "Save changes" alert are rebuilt point by point against Photoshop 2026.
2. **Interface fonts**: Photoshop panels and UXP dialogs use Adobe Clean (an Adobe proprietary font that cannot be bundled; approximated with Source Sans 3, which makes long sentences about 2.5% wider). Classic dialogs, alerts, and window titles use the system font drawn by AppKit (`theme::dialog`, opsz 17 plus trak tracking, matching Photoshop's widths). New Layer, Duplicate Layer, Lock Layers, Canvas Size, Trim, New Guide, Select › Modify (UXP) and Fill (AppKit), alerts, and the adjustment and filter dialogs are calibrated according to this distinction. The Color Picker (AppKit) also uses the system font; File › New is replaced with Photoshop 2026's new New Document dialog (UXP) and positioned against screenshots.

### P1

3. **Layer operations**: done for P1. New Layer (⇧⌘N), Layer from Background..., the Duplicate Layer... dialog, Rename Layer..., Flatten Image's "Discard hidden layers?" prompt; layer groups (data structure, compositing and Pass Through, ⌘G / ⇧⌘G, the New Group dialog, the delete-group prompt, duplicating, panel display and collapsing, dragging in and out, moving/aligning/transforming as a whole, group layer masks with their panel row, PSD groups); multi-select, Merge Layers, All Layers / Deselect Layers, Align / Distribute (including linked layers), locks (dialog, ⌘/, the five buttons, PSD `lspf`, group locks), Link / Unlink / Select Linked Layers with linked layers following the Move tool, Free Transform and Align, ⇧-click to disable a link (red ×), PSD links, dragging onto footer buttons, multi-row reordering, ⌥-click expanding subgroups and auto-scrolling to the active layer are implemented. Moved out: New Layer's "Use previous layer to create clipping mask" → P2 #15 (needs clipping masks); Duplicate Layer's Artboard destination → P3 #23 (needs artboards).
4. **Image size and orientation**: done for P1. The Image Size dialog is rebuilt against Photoshop 2026 (100% preview, units, Fit To presets, eight resampling methods with ⌥ number keys, the linkage between Resample and resolution), with the Auto Resolution... sheet, Save/Load/Delete Preset... with Photoshop's `.imz` files and the Delete Preset sheet, Preserve Details' Reduce Noise slider, native macOS dropdown menus (shared with the AppKit-style dialogs through `native_popup`), and resizing the window by dragging; Image Rotation › Arbitrary...'s Rotate Canvas dialog and arbitrary-angle rotation are implemented. Moved out: the actual effect of Scale Styles → P2 #16 (needs layer styles); Photoshop's own Preserve Details / Preserve Details 2.0 algorithms (Adobe's proprietary and machine-learning upscalers; approximated with Lanczos and an edge-keeping noise reduction) → P3 #26.
5. **Crop tool**: done for P1. The options bar is rebuilt pixel by pixel against Photoshop 2026 with native menus; ratio and size presets, Front Image, saved presets (New/Delete Crop Preset... with their dialogs), W x H x Resolution resampling, expanding the canvas when cropping beyond it, Delete Cropped Pixels, six overlays, the Linear Light-blended shield with a custom color and Auto Adjust Opacity, the box staying centered while the image moves in non-Classic mode, Classic Mode (the box moves and turns on the still image), dragging outside the box to rotate (Shift 15°), Straighten, the temporary "Crop Preview" layer and tab title, cropping when another tool is picked (Photoshop 2026 doesn't ask), and the Perspective Crop tool are implemented. Moved out: Fill's Generative Expand → P3 #27 (Adobe cloud); Content-Aware Fill → P3 #26 (content-aware engine).
6. **Remaining transform items**: Split Warp, grid size, warp style presets (Arc, Flag, Wave, etc.) and Bend; dragging the reference point on the canvas, and mouse scaling and rotation around the reference point; pixel-level comparison of the transform box and handle appearance. (The options bar's X/Y/W/H/angle/skew numeric input, reference point selection, relative positioning, width/height linking, and six interpolation methods are implemented against Photoshop 2026; Select › Transform Selection and Warp (Bézier mesh, dragging control points and the surface) are also implemented.) (Skew, Distort, Perspective—the Edit › Transform modes, ⌘ / ⌘⇧ / ⌘⌥⇧ dragging, projective transforms—and the right-click menu during a transform are implemented.)
7. **Adjustments**: Image › Adjustments' Color Lookup, Shadows/Highlights, HDR Toning, Replace Color, Match Color; presets for Levels and Curves, Photoshop 2026's default Auto algorithm and Options..., eyedroppers, Curves' pencil mode and Smooth, Show Clipping, numeric input; Black & White's Auto; Photo Filter's Photoshop color picker; Vibrance slider skin-tone protection; Gradient Map's gradient editor and multiple color stops, Dither; Auto Color's midtone neutralization; Hue/Saturation's eyedroppers, Invert, targeted adjustment, and presets; Brightness/Contrast's Auto matching Photoshop; each adjustment dialog remembering its last values. (Levels and Curves are rebuilt against Photoshop 2026's classic dialogs, supporting single channels, display options, and Auto; Brightness/Contrast, Color Balance, and Hue/Saturation are rebuilt as UXP dialogs; the algorithms of all five are calibrated against measured Photoshop data; Channel Mixer and Selective Color are implemented, with algorithms differing from Photoshop by no more than 1 level, and their dialogs are rebuilt as the UXP versions, but the preset list does not exist yet; the dialogs of Vibrance, Posterize, Exposure, Photo Filter, and Black & White are rebuilt as UXP versions, and Exposure, Photo Filter, Black & White (including Tint), and Vibrance's Saturation are calibrated against Photoshop's values.)
8. **Filters**: Blur's Lens/Radial/Shape/Smart Blur; Blur Gallery; Distort's Displace, Shear, Wave; Noise's Reduce Noise; Render's Flame, Picture Frame, Tree, Fibers and Lens Flare; Sharpen's Smart Sharpen; Stylize's Extrude, Oil Paint; further checking of Wind's random distribution against Photoshop; exact algorithms for diagonal Motion Blur, diagonal Emboss, and Minimum/Maximum round mode; Video; zooming and dragging in the filter dialog preview box; detail differences between the distortion diagrams and Photoshop; Filter Gallery; checking value details of implemented filters against Photoshop (Add Noise's strength, Offset's "Set to Background" label on the background layer). (Gaussian Blur, Box Blur, Unsharp Mask, Median, square Minimum/Maximum, High Pass, Mosaic, and Solarize are checked level by level against Photoshop; Blur, Blur More, Sharpen, Sharpen More, Find Edges, Motion Blur, and Emboss are implemented; Fragment, Custom, Surface Blur, Dust & Scratches, Despeckle, Sharpen Edges, and Trace Contour are checked against Photoshop, and the Custom dialog is rebuilt against Photoshop and supports .acf loading/saving; classic filter dialogs with settings are rebuilt point by point against Photoshop 2026, with a preview box, and remember their last values; Twirl, Pinch, Spherize, and Polar Coordinates are rebuilt as plugin-style dialogs with distortion diagrams.)
9. **File**: reading and writing PSD adjustment layers, 16/32-bit and CMYK and other modes, and ZIP-compressed data; Photoshop's option dialogs on save (PNG/JPEG options, the prompt when saving multiple layers to a flat format); Adobe Stock templates and search in the New Document dialog, saving recently used and saved presets across launches, artboard options, switching color mode, bit depth, and color profile, Quick Export as PNG, the remaining items of the File › Export submenu; pixel-level comparison of the unsaved-changes confirmation with Photoshop; verifying written layer masks by opening them in Photoshop.
10. **Other tools**: the Brush tool's brush presets, brush tip shapes, pressure sensitivity, and smoothing; the Gradient tool's gradient editor and presets, Dither, Method (Perceptual/Linear/Classic), transparency gradients, and the "gradient fill layer" mode that is the default since Photoshop 2024; the Info panel's Photoshop layout (section icons and dividers), the Pattern Stamp's pattern selection and Impressionist, Art History Brush, the Clone Source panel, the retouching tools' Protect Tones/Vibrance/Protect Detail and the effect accumulating continuously while holding and dragging, Mixer Brush and Adjustment Brush (the toolbar already has buttons for them, but they have no behavior yet), the Selection Brush's Selection Bar.
11. **View**: snapping for Free Transform, the Crop tool and guides being dragged (View › Snap and Snap To work for the marquees, shapes and the Move tool), Smart Guides for tools other than the Move tool and their distance labels, canvas guides, guide layouts, Edit/Clear Selected Guides, guide and grid color settings, saving guides to PSD; revealing hidden panels at the screen's sides in Full Screen Mode, the remaining Show items (Target Path, Canvas Guides, Count, Slices, Notes, etc.), Proof Setup/Colors and Gamut Warning.
12. **Panels**: the remaining items of Navigator/Info/Histogram (panel options, expanded view, editable zoom), Brushes and Brush Settings, Channels, Paths, Adjustments, Gradients, Patterns, Styles, Actions, Character, Paragraph, Tool Presets, Clone Source, Layer Comps, Notes, Timeline, etc.; dragging panels to dock, float, and collapse to icons; Window › Workspace.

### P2

13. **Type**: re-editable type layers (currently text becomes a raster layer once committed), insertion point movement and text selection, the system font list, kerning/tracking/leading, paragraph text (text boxes), vertical type and the Type Mask tools, the Character and Paragraph panels, the Type menu (anti-aliasing, Convert to Shape, Warp Text, Rasterize, etc.), complex text shaping and font fallback.
14. **Paths and shapes**: Pen/Freeform Pen/Curvature Pen, anchor point tools, Path Selection/Direct Selection, the Paths panel; vector shape layers (currently the shape tools produce raster layers), live shape properties, rounded corners, strokes, the Custom Shape tool, Path/Pixels modes, Combine Shapes.
15. **Masks**: creating a mask from transparency (From Transparency), linking masks to layers (the mask follows when the layer is moved or transformed), ⌥-clicking to view the mask, the mask Properties panel (density, feather), applying filters and adjustments to masks; vector masks, clipping masks (⌥⌘G) and the New Layer dialog's clipping option (moved from P1 #3), Quick Mask options (color, showing selected areas), Select and Mask (⌥⌘R), Save/Load Selection.
16. **Layer styles** (including Image Size's Scale Styles, moved from P1 #4): Blending Options, Bevel & Emboss, Stroke, Inner Shadow, Inner Glow, Satin, Color/Gradient/Pattern Overlay, Outer Glow, Drop Shadow.
17. **Fill layers and adjustment layers**: Layer › New Fill Layer, New Adjustment Layer.
18. **Remaining Select menu items**: Color Range, Focus Area, All Layers/Deselect Layers/Find Layers/Isolate Layers; Modify's "Apply effect at canvas bounds" for Smooth and Feather; the marquee tools' Fixed Ratio / Fixed Size styles.
19. **Color modes and bit depth**: Image › Mode's Grayscale, Bitmap, Duotone, Indexed Color, CMYK, Lab, Multichannel, 16/32 bits per channel; Color Settings, Assign/Convert to Profile; CMYK values matching Photoshop (requires ICC color management).
20. **Remaining Color Picker items**: the naming dialog for "Add to Swatches", Color Libraries, the CMYK out-of-gamut warning, sampling colors from the document while the color picker is open.
21. **Remaining History panel items**: snapshots, New Document from state, different icons per operation type, History Options.

### P3

22. **Smart Objects and Smart Filters**, Place Embedded/Linked, Package.
23. **Artboards and the Frame tool** (including Duplicate Layer's Artboard destination, moved from P1 #3), the Slice tool and Save for Web, the remaining Export submenu items (Artboards/Layer Comps/Layers to Files, etc.).
24. **Video and animation**: Timeline, Video Layers, Render Video.
25. **Automation**: Actions, Batch, Scripts, Image Processor, Droplet, Data Sets and Variables.
26. **Professional filters and tools**: Photoshop's exact Preserve Details / Preserve Details 2.0 upscaling (moved from P1 #4), Liquify, Camera Raw Filter, Lens Correction, Adaptive Wide Angle, Vanishing Point, Puppet Warp, Perspective Warp, Content-Aware Scale/Fill/Move (including the Crop tool's Content-Aware Fill, moved from P1 #5), Auto-Align/Blend Layers, Photomerge, Merge to HDR Pro, Apply Image, Calculations, Trap, Analysis (measurement, counting), 3D/Materials.
27. **Features that depend on Adobe cloud and AI**: Generative Fill/Expand/Upscale (including the Crop tool's Generative Expand, moved from P1 #5), Generate Image, Neural Filters, AI Denoise/Sharpen, Select Subject/Sky, Sky Replacement, Remove Background, Reflection Removal, Harmonize, Adobe Stock, Libraries, Bridge, Firefly Boards, Invite to Edit, Share for Review, Version History, Content Credentials, the Contextual Task Bar.
28. **Other**: printing, File Info, the Plugins menu, Keyboard Shortcuts and Menus customization, Preset Manager, Purge, Help menu contents.
