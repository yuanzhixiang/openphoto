# OpenPhoto Product Specification Overview

## Product Positioning

OpenPhoto is a Photoshop clone written in Rust. Its goal is to match Photoshop 2026 in features, interaction, and keyboard shortcuts, and to match the original Photoshop interface pixel for pixel (compared pixel by pixel at the same window size). The reference is a running Photoshop 2026 (macOS, default "Medium Gray" theme, Essentials workspace). The specific behavior of each module is in the spec at the corresponding source path; the overall UI-layer specification is in `crates/op-ui/src/README.md`.

Besides the graphical interface, `op-mcp` is an MCP server: AI agents use it to invoke the same editing operations as the interface (adjustments, filters, layers, selections, canvas, fill, history); see `crates/op-mcp/src/main.md`.

## Feature Gaps Relative to Photoshop

This section lists features that Photoshop 2026 has and OpenPhoto currently lacks (or has only in part), ordered by priority. The data comes from Photoshop 2026's menus, toolbar, and panels. Each item is deleted or rewritten here as soon as it is filled in, so this section always describes the current gaps.

Priorities:

- **P0**: An existing interface differs from Photoshop, or a feature required by the most basic editing flow (open → select → paint/modify → undo → export) is missing.
- **P1**: Commonly used editing features.
- **P2**: Fairly commonly used features that take substantial implementation work.
- **P3**: Professional, rarely used, or Adobe cloud-dependent features.

### P0

1. **Pixel-level calibration of existing interfaces**: Image Size (Photoshop also has a preview image on the left), Fill, Trim, and the adjustment and filter dialogs are aligned pixel by pixel; the Layers panel's rename field and drag indicator line are measured against Photoshop 2026; the window frame (the outer dimensions of the title bar, options bar, toolbar, icon column, and panel column; the document tab bar, scroll bars, status bar), the History panel, and the Color Picker are measured 1:1 against Photoshop (the Color Picker's hex field receives focus on open, and the marker in the color field is clipped to the field). The options bars of all tools are positioned one by one against Photoshop 2026 screenshots (separators and the edges of the various boxes differ by no more than 1 pt). What has not yet been compared pixel by pixel: the details of the toolbar icons (each has been redrawn in Photoshop's style and aligned in position, but the shapes of the line-style icons are still approximate; see `crates/op-ui/src/tool_icons.md`). The panel column's collapse bar, group heights, tab bar, Color, Properties (including the Rulers & Grids, Guides, and Quick Actions sections after Canvas), the Layers panel, the icon column, and the bottom of the toolbar are aligned pixel by pixel; the Canvas Size, Fill, Trim, New Guide, and Select › Modify dialogs and the "Save changes" alert are rebuilt point by point against Photoshop 2026.
2. **Interface fonts**: Photoshop panels and UXP dialogs use Adobe Clean (an Adobe proprietary font that cannot be bundled; approximated with Source Sans 3, which makes long sentences about 2.5% wider). Classic dialogs, alerts, and window titles use the system font drawn by AppKit (`theme::dialog`, opsz 17 plus trak tracking, matching Photoshop's widths). New Layer, Duplicate Layer, Lock Layers, Canvas Size, Trim, New Guide, Select › Modify (UXP) and Fill (AppKit), alerts, and the adjustment and filter dialogs are calibrated according to this distinction. The Color Picker (AppKit) also uses the system font; File › New is replaced with Photoshop 2026's new New Document dialog (UXP) and positioned against screenshots.

### P1

3. **Layer operations**: done for P1. New Layer (⇧⌘N), Layer from Background..., the Duplicate Layer... dialog, Rename Layer..., Flatten Image's "Discard hidden layers?" prompt; layer groups (data structure, compositing and Pass Through, ⌘G / ⇧⌘G, the New Group dialog, the delete-group prompt, duplicating, panel display and collapsing, dragging in and out, moving/aligning/transforming as a whole, group layer masks with their panel row, PSD groups); multi-select, Merge Layers, All Layers / Deselect Layers, Align / Distribute (including linked layers), locks (dialog, ⌘/, the five buttons, PSD `lspf`, group locks), Link / Unlink / Select Linked Layers with linked layers following the Move tool, Free Transform and Align, ⇧-click to disable a link (red ×), PSD links, dragging onto footer buttons, multi-row reordering, ⌥-click expanding subgroups and auto-scrolling to the active layer are implemented. Moved out: New Layer's "Use previous layer to create clipping mask" → P2 #15 (needs clipping masks); Duplicate Layer's Artboard destination → P3 #23 (needs artboards).
4. **Image size and orientation**: done for P1. The Image Size dialog is rebuilt against Photoshop 2026 (100% preview, units, Fit To presets, eight resampling methods with ⌥ number keys, the linkage between Resample and resolution), with the Auto Resolution... sheet, Save/Load/Delete Preset... with Photoshop's `.imz` files and the Delete Preset sheet, Preserve Details' Reduce Noise slider, native macOS dropdown menus (shared with the AppKit-style dialogs through `native_popup`), and resizing the window by dragging; Image Rotation › Arbitrary...'s Rotate Canvas dialog and arbitrary-angle rotation are implemented. Moved out: the actual effect of Scale Styles → P2 #16 (needs layer styles); Photoshop's own Preserve Details / Preserve Details 2.0 algorithms (Adobe's proprietary and machine-learning upscalers; approximated with Lanczos and an edge-keeping noise reduction) → P3 #26.
5. **Crop tool**: done for P1. The options bar is rebuilt pixel by pixel against Photoshop 2026 with native menus; ratio and size presets, Front Image, saved presets (New/Delete Crop Preset... with their dialogs), W x H x Resolution resampling, expanding the canvas when cropping beyond it, Delete Cropped Pixels, six overlays, the Linear Light-blended shield with a custom color and Auto Adjust Opacity, the box staying centered while the image moves in non-Classic mode, Classic Mode (the box moves and turns on the still image), dragging outside the box to rotate (Shift 15°), Straighten, the temporary "Crop Preview" layer and tab title, cropping when another tool is picked (Photoshop 2026 doesn't ask), and the Perspective Crop tool are implemented. Moved out: Fill's Generative Expand → P3 #27 (Adobe cloud); Content-Aware Fill → P3 #26 (content-aware engine).
6. **Remaining transform items**: measuring Warp's Custom Grid Size dialog, and the pixel-level comparison of the transform box and handle appearance with Photoshop 2026. (The options bar's X/Y/W/H/angle/skew numeric input, reference point selection, relative positioning, width/height linking and six interpolation methods; mouse rotation and ⌥ scaling around the reference point and dragging it on the canvas; Skew, Distort, Perspective and the right-click menu; Select › Transform Selection; Warp with Bézier patches, dragging control points and the surface, Split Crosswise/Vertically/Horizontally, grid sizes (with Custom...), the 15 preset styles with Bend/H/V and orientation are implemented.)
7. **Adjustments**: measuring the Auto Color Correction Options dialog against Photoshop; measuring the Shadows/Highlights (both layouts), HDR Toning, Replace Color (with its selection preview), Match Color and Color Lookup dialogs against Photoshop. (Levels and Curves (classic dialogs, single channels, display options, Auto, Photoshop's presets, Set Black/Gray/White Point eyedroppers; Curves' pencil with Smooth, typed Input/Output, Show Clipping and the targeted adjustment hand), Brightness/Contrast, Color Balance, Hue/Saturation (presets, eyedroppers, Invert, targeted adjustment hand), Channel Mixer and Black & White and Exposure (presets), Selective Color, Vibrance (with skin-tone protection), Posterize, Photo Filter (Photoshop's Color Picker), Threshold, Gradient Map (with the Gradient Editor, multiple stops and Dither) are implemented, calibrated against Photoshop where measured; Shadows/Highlights, HDR Toning, Replace Color, Match Color and Color Lookup (.cube/.3dl) work with provisional dialogs; choosing an adjustment with Option opens its last settings; Levels' and Curves' Auto with the four algorithms of Auto Color Correction Options (target colors, clipping, Snap Neutral Midtones, Save as defaults), Auto Color's Find Dark & Light Colors with midtone neutralization, and Black & White's Auto.) Moved out: Brightness/Contrast's Auto and Levels'/Curves' Enhance Brightness and Contrast matching Photoshop exactly → P3 #26 (Adobe's undisclosed algorithm; the current fits are documented in `brightness_contrast.md` and `auto.md`).
8. **Filters**: further checking of Wind's random distribution against Photoshop; exact algorithms for diagonal Motion Blur, diagonal Emboss, and Minimum/Maximum round mode; detail differences between the distortion diagrams and Photoshop; checking value details of implemented filters against Photoshop (Add Noise's strength); measuring the new filters' dialogs against Photoshop (Radial Blur's center, Shear's curve grid, Lens Blur's iris controls, Wave's Randomize). (The filter dialogs' preview zooms and pans. Gaussian Blur, Box Blur, Unsharp Mask, Median, square Minimum/Maximum, High Pass, Mosaic, and Solarize are checked level by level against Photoshop; Blur, Blur More, Sharpen, Sharpen More, Find Edges, Motion Blur, Emboss, Fragment, Custom (.acf), Surface Blur, Dust & Scratches, Despeckle, Sharpen Edges, Trace Contour, the Distort, Pixelate, Render Clouds and Stylize filters are implemented with rebuilt dialogs; Radial, Smart, Shape and Lens Blur, Displace, Shear, Wave, Reduce Noise, Smart Sharpen, Fibers, Lens Flare, Extrude and Oil Paint work with provisional dialogs.) Moved out: Blur Gallery → P2 (an on-canvas workspace of its own: substantial work); Filter Gallery → P2 (a workspace of its own with an effect stack, and 47 separate artistic filters, each its own algorithm); Render › Flame → P2 #14 (it renders along paths); Render › Picture Frame and Tree → P3 #26 (Photoshop's procedural artwork libraries); Video → P3 #24.
9. **File**: measuring the JPEG Options and PNG Format Options dialogs against Photoshop; pixel-level comparison of the unsaved-changes confirmation with Photoshop; verifying written layer masks by opening them in Photoshop. (PSD reading handles ZIP-compressed data, with and without prediction; the New Document dialog keeps Recent and Saved across launches; File › Export › Quick Export as PNG and Layer › Quick Export as PNG / Export As... work, and the Export submenu lists all of Photoshop's items; saving a JPEG or PNG asks for JPEG Options or PNG Format Options, and a layered document saved to a flat format is a flattened copy, as in Photoshop 2026.) Moved out: reading and writing PSD adjustment layers → P2 #17 (needs adjustment layers); 16/32-bit, CMYK and other modes in PSD files, and switching color mode, bit depth and color profile in the New Document dialog → P2 #19 (needs those modes); the New Document dialog's artboard options → P3 #23 (needs artboards); its Adobe Stock templates and search → P3 #27 (Adobe cloud); Export › Export Preferences... → P3 #28 (it opens Photoshop's Preferences window, which isn't built); Layers to Files... and Data Sets as Files... → P3 #25 (Photoshop's scripts and data sets); Paths to Illustrator... → P2 #14 (needs paths); Color Lookup Tables... → P2 #17 (exports adjustment layers); Render Video... → P3 #24; Zoomify... → P3 #28; Save for Web (Legacy)..., Artboards and Layer Comps to Files/PDF stay with P3 #23.
10. **Other tools**: comparing the Clone Source panel's layout with Photoshop's (the Gradient Editor, presets, Dither, Method and transparency gradients are implemented; the painting tools have General Brushes presets, elliptical tips with angle, roundness and spacing, pen pressure for size, opacity and flow, Smoothing and the airbrush; the retouching tools build up as they are dragged and have Protect Tones, Vibrance and Protect Detail; the Pattern Stamp picks among patterns made with Edit › Define Pattern... and paints Impressionist daubs; the Mixer Brush loads, picks up and mixes paint with its combinations; the Art History Brush paints the history source in its ten styles; the Clone Source panel has five sources, offset, scale, angle and the overlay); the Info panel's Photoshop layout (section icons and dividers). Moved out: the Gradient tool's gradient fill layer mode and the Adjustment Brush (it paints adjustment layers) → P2 #17 (need fill and adjustment layers); the Selection Brush's Selection Bar → P3 #27 (it is Photoshop's Contextual Task Bar).
11. **View**: done for P1. (Hidden panels and tools come back at the window's sides; View › Snap and Snap To work for the marquees, shapes, the Move tool, Free Transform, the Crop tool and guides being dragged; guides are saved in and read from PSD files; View › Guides › New Guide Layout... makes column, row and margin guides; guides can be selected, edited and cleared, and Show › Canvas Guides works; Smart Guides line up marquees and shapes too, label distances, space boxes equally and measure on ⌘-hover.) Moved out: guide and grid color settings → P3 #28 (they are in Photoshop's Preferences window); Show › Target Path → P2 #14 (needs paths); Show › Count → P3 #26 (the Count tool is part of Analysis); Show › Slices and the artboard items → P3 #23; Show › Notes → P3 #28 (needs the Note tool's annotations); Proof Setup, Proof Colors and Gamut Warning → P2 #19 (need color management).
12. **Panels**: the remaining items of Navigator/Info/Histogram (panel options, expanded view, editable zoom), Brushes and Brush Settings, Paths, Adjustments, Styles, Actions, Character, Paragraph, Tool Presets, Clone Source, Layer Comps, Notes, Timeline, etc.; dragging panels to dock, float, and collapse to icons; Window › Workspace.

### P2

13. **Type**: re-editable type layers (currently text becomes a raster layer once committed), insertion point movement and text selection, the system font list, kerning/tracking/leading, paragraph text (text boxes), vertical type and the Type Mask tools, the Character and Paragraph panels, the Type menu (anti-aliasing, Convert to Shape, Warp Text, Rasterize, etc.), complex text shaping and font fallback.
14. **Paths and shapes** (including Render › Flame, moved from P1 #8, Export › Paths to Illustrator..., moved from P1 #9, and View › Show › Target Path, moved from P1 #11): Pen/Freeform Pen/Curvature Pen, anchor point tools, Path Selection/Direct Selection, the Paths panel; vector shape layers (currently the shape tools produce raster layers), live shape properties, rounded corners, strokes, the Custom Shape tool, Path/Pixels modes, Combine Shapes.
15. **Masks**: creating a mask from transparency (From Transparency), linking masks to layers (the mask follows when the layer is moved or transformed), ⌥-clicking to view the mask, the mask Properties panel (density, feather), applying filters and adjustments to masks; vector masks, clipping masks (⌥⌘G) and the New Layer dialog's clipping option (moved from P1 #3), Quick Mask options (color, showing selected areas), Select and Mask (⌥⌘R), Save/Load Selection.
16. **Layer styles** (including Image Size's Scale Styles, moved from P1 #4): Blending Options, Bevel & Emboss, Stroke, Inner Shadow, Inner Glow, Satin, Color/Gradient/Pattern Overlay, Outer Glow, Drop Shadow.
17. **Fill layers and adjustment layers**: Layer › New Fill Layer, New Adjustment Layer, the Gradient tool's gradient fill layer mode and the Adjustment Brush (moved from P1 #10), and reading and writing them in PSD files and Export › Color Lookup Tables... (moved from P1 #9).
18. **Remaining Select menu items**: Color Range, Focus Area, All Layers/Deselect Layers/Find Layers/Isolate Layers; Modify's "Apply effect at canvas bounds" for Smooth and Feather; the marquee tools' Fixed Ratio / Fixed Size styles.
19. **Color modes and bit depth** (including PSD files in those modes and the New Document dialog's color mode, bit depth and profile, moved from P1 #9, and View › Proof Setup, Proof Colors and Gamut Warning, moved from P1 #11): Image › Mode's Grayscale, Bitmap, Duotone, Indexed Color, CMYK, Lab, Multichannel, 16/32 bits per channel; Color Settings, Assign/Convert to Profile; CMYK values matching Photoshop (requires ICC color management).
20. **Remaining Color Picker items**: the naming dialog for "Add to Swatches", Color Libraries, the CMYK out-of-gamut warning, sampling colors from the document while the color picker is open.
21. **Remaining History panel items**: snapshots, New Document from state, different icons per operation type, History Options.
- **Blur Gallery** (moved from P1 #8): Field, Iris, Tilt-Shift, Path and Spin Blur with their on-canvas pins, a workspace of its own.
- **Filter Gallery** (moved from P1 #8): the gallery window with its preview, category folders, thumbnails and effect layer stack, and its Artistic, Brush Strokes, Distort (Diffuse Glow, Glass, Ocean Ripple), Sketch, Stylize (Glowing Edges) and Texture filters.
